Cross-cloud AI-infrastructure monitoring for regulated systems.

GlassHood is a cross-cloud monitoring engine for regulated systems: live topology reconciled against declared design, with compliance evidence derived from what it observes. It runs on Azure and reads a Google Cloud estate through Workload Identity Federation — no stored keys.

Live demo → See the architecture →

Read-only by design

GlassHood installs nothing in the system it watches. Every call toward the monitored system is list, get or describe, made with a short-lived, viewer-only federated token.

Live topology against declared design

Live discovery is merged with declarative YAML manifests into one graph, rebuilt every cycle, so the gap between what was designed and what is actually running is visible.

Compliance as a byproduct of observation

Evidence is derived from what the engine observed, not self-attestation — aligned to Annex 11 / ALCOA+ / Part 11.
